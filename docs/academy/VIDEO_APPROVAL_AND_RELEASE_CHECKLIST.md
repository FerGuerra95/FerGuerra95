# Video Approval and Release Checklist

Use before publishing, sending, embedding, or linking any CEO's OS academy video.

## Data and Security

- [ ] Uses synthetic/IberNova data only.
- [ ] No real client data.
- [ ] No real prospect or target data.
- [ ] No secrets.
- [ ] No tokens, cookies, auth headers, session IDs, or API keys.
- [ ] No browser private info.
- [ ] No local sensitive paths.

## Product Truthfulness

- [ ] DSS positioning clear.
- [ ] Human Review Required clear.
- [ ] Board Review Draft wording clear.
- [ ] No board-approved claim.
- [ ] No certified PDF claim.
- [ ] No autonomous AI claim.
- [ ] No legal/investment advice.
- [ ] No fairness opinion.
- [ ] No certified compliance.
- [ ] No SOC2/ISO claim.
- [ ] No production AI provider traffic claim.
- [ ] Bridge/Heritage labelled future/internal/demo.
- [ ] PDF/export wording correct.

## Production Quality

- [ ] Visual QA passed.
- [ ] Captions reviewed.
- [ ] Audio reviewed.
- [ ] Script approved.
- [ ] No clipped labels.
- [ ] No low-contrast critical labels.
- [ ] No loading skeletons or broken routes.

## Avatar / Voice

- [ ] Founder avatar approved if used.
- [ ] Founder voice approved if used.
- [ ] AI-generated presenter disclosed where appropriate.
- [ ] No fake testimonial.
- [ ] No unapproved likeness.

## Release Controls

- [ ] Link access controlled.
- [ ] Version assigned.
- [ ] Hosting location approved.
- [ ] Link owner assigned.
- [ ] Old versions archived or revoked if needed.
- [ ] Release notes recorded.

## Decision

| Result | Action |
|---|---|
| All checks pass | Release to intended audience |
| Minor visual/caption issue | Fix and re-review |
| Claim/data/security issue | Block release |
| Consent issue | Block release |
