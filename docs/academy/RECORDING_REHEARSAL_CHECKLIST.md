# Recording Rehearsal Checklist

Run this checklist before a rehearsal or final recording session.

## Environment

- [ ] App environment ready.
- [ ] IberNova/synthetic data only.
- [ ] No real client data.
- [ ] Login route tested.
- [ ] CEO Overview tested.
- [ ] Reporting / Board Packs tested.
- [ ] Snapshot creation and preview tested.
- [ ] Browser print/save-as-PDF tested.
- [ ] Funding tested.
- [ ] M&A tested.
- [ ] Compliance/Risk tested.
- [ ] Bridge/Heritage labels checked.

## Visual Safety

- [ ] No console visible.
- [ ] No browser bookmarks/private data.
- [ ] No local paths or logs.
- [ ] No tokens, cookies, auth headers, or session IDs.
- [ ] No `NaN`.
- [ ] No `undefined`.
- [ ] No `Infinity`.
- [ ] No ErrorBoundary.
- [ ] No black screen.
- [ ] No loading skeletons in final take.

## Recording Setup

- [ ] Audio check passed.
- [ ] Resolution check passed.
- [ ] Zoom level set.
- [ ] Recording tool tested.
- [ ] Microphone/source selected.
- [ ] Notifications disabled.
- [ ] Narration script ready.
- [ ] Chapter plan open outside recording frame.
- [ ] Retake folder ready outside repository.

## Stop / Retry Conditions

Stop and retry if:

- A forbidden claim is spoken.
- A real or sensitive value appears.
- A route breaks.
- A screen is visually broken.
- PDF/export wording drifts into "certified PDF".
- Missing data is hidden.
- An avatar/voice is used without approval.
