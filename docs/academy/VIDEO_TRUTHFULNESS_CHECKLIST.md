# Video Truthfulness Checklist

Use this checklist before publishing any CEO's OS visual academy video, screenshot deck, avatar intro, or visual manual page.

## Required Claims

- [ ] CEO's OS is described as a Private Executive DSS.
- [ ] Human Review Required is visible or stated.
- [ ] Board Review Draft is described as a draft/review artifact.
- [ ] IberNova or other demo data is labelled synthetic.
- [ ] Missing data remains visible.
- [ ] AI, if mentioned, is draft-assistant/planning only unless a future approved runtime exists.
- [ ] No real client data appears.

## Forbidden Claims

The asset must not claim:

- [ ] Board-approved output.
- [ ] Certified PDF.
- [ ] Enterprise certification.
- [ ] Procurement readiness.
- [ ] SOC2/ISO certification.
- [ ] Autonomous AI decision-making.
- [ ] Legal advice.
- [ ] Investment advice.
- [ ] Fairness opinion.
- [ ] Certified compliance.
- [ ] Public marketplace live.
- [ ] Production AI provider traffic.
- [ ] Real client case study unless separately approved and documented.

## Screen Safety

- [ ] No secrets, tokens, cookies, auth headers, API keys, private keys, or session IDs.
- [ ] No local file paths or debug console with sensitive values.
- [ ] No real target names, prospect notes, emails, phone numbers, or personal data.
- [ ] No hidden error boundary, NaN, undefined, Infinity, or fake 0 replacing N/A.
- [ ] Browser tabs/bookmarks do not reveal private data.

## Product Accuracy

- [ ] CEO Overview is explained as aggregator only.
- [ ] Reporting snapshot preview is explained as persisted renderer input/status metadata.
- [ ] reviewed/internal_final are human workflow states, not board approval.
- [ ] Funding scenarios are not investment recommendations.
- [ ] M&A valuation is not a fairness opinion.
- [ ] Compliance is not a certified audit.
- [ ] Bridge is internal/unlisted/demo only.
- [ ] Heritage is future/premium unless supported by explicit data.

## Export / PDF Wording Rules

- [ ] If the video shows `Ctrl+P` or browser print, call it "browser-native print/save-as-PDF."
- [ ] If a PDF file is saved, call it a "convenience copy of the HTML Board Review Draft."
- [ ] Do not call it a certified PDF.
- [ ] Do not imply CEO's OS has implemented binary PDF generation if the workflow is browser-native.
- [ ] Do not imply the saved PDF is legally approved, board-approved, digitally signed, filed, or certified.
- [ ] State that the saved copy must be reviewed before sharing.

## Publication Decision

| Result | Action |
|---|---|
| All checks pass | Publish or share according to access level |
| Minor wording issue | Edit script/caption and re-review |
| Any forbidden claim | Block publication |
| Any secret/real data exposure | Block publication and delete draft from unsafe location |
