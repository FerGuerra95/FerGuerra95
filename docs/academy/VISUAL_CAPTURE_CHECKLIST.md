# Visual Capture Checklist

Use this checklist before capturing screenshots or recording any CEO's OS Visual Academy material.

## Global Pre-Capture Checklist

- [ ] Use only IberNova Industrial Group S.L. or clearly synthetic data.
- [ ] Confirm no real client, prospect, target, employee, or personal data is visible.
- [ ] Confirm no tokens, cookies, auth headers, session IDs, API keys, private keys, `.env` files, local sensitive paths, terminal logs, or debug console are visible.
- [ ] Confirm navigation stability before capture.
- [ ] Confirm browser zoom and recording resolution are set.
- [ ] Confirm visual theme is correct and consistent.
- [ ] Confirm no `NaN`, `undefined`, `Infinity`, error boundary, black screen, or stale loading skeleton appears.
- [ ] Confirm N/A and insufficient_data are visible and explained where data is missing.
- [ ] Confirm Board Review Draft screens show Human Review Required.
- [ ] Confirm Not Board Approved is visible where applicable.
- [ ] Confirm no board-approved wording appears.
- [ ] Confirm no certified PDF wording appears.
- [ ] Confirm no autonomous AI wording appears.
- [ ] Confirm no legal advice, investment advice, fairness opinion, certified compliance, SOC2/ISO, procurement-ready, or public marketplace claim appears.
- [ ] Confirm Bridge and Heritage are labelled demo/future/internal when shown.
- [ ] Confirm browser export/PDF is explained as print/save-as-PDF from the browser, not a CEO's OS certified PDF export.

## Capture Environment

| Item | Required setting |
|---|---|
| Data | IberNova/synthetic only |
| Browser zoom | 90-100% unless a screen needs more room |
| Resolution | 1920x1080 preferred |
| Browser UI | Clean tabs, no private bookmarks |
| Console | Closed |
| Notifications | Disabled |
| Account menu | Avoid showing email/private identity unless synthetic |
| Recording destination | Outside repo |

## Block Capture If

- Any real or sensitive data appears.
- Any secret/token/session value appears.
- A forbidden product claim appears.
- A screen is visually broken.
- Missing data is hidden or converted into fake certainty.
- The route is wrong or stale.
- The screen implies Bridge marketplace is live.
- The screen implies PDF certification or board approval.
