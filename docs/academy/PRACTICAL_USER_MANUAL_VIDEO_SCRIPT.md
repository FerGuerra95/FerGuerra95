# CEO's OS Practical User Manual - Synthetic Demo Edition

## Purpose

This script defines a 35-60 minute practical walkthrough video for CEO's OS / The Sovereign OS. The video is a user manual, not a commercial hype reel. It should teach a qualified pilot user how to enter the app, navigate branches, create a persisted Board Review snapshot, open the HTML Board Review Draft preview, and save/print the draft from the browser.

No video, image, audio, or media asset is generated in C.24.2.

## Required Boundaries

- Use IberNova Industrial Group S.L. or other synthetic data only.
- Preserve DSS and Human Review Required language.
- Do not say board-approved.
- Do not say certified PDF.
- Do not say autonomous AI.
- Do not say legal advice, investment advice, fairness opinion, or certified compliance.
- Do not imply production AI provider traffic.
- Do not show secrets, tokens, cookies, auth headers, session IDs, real client data, or real target data.
