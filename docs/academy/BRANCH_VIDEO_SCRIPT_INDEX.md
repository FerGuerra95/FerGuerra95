# Branch Video Script Index

## Global Script Pattern

Use this structure for every video:

1. Open with the executive problem.
2. State the DSS boundary.
3. Show the relevant IberNova or synthetic screen.
4. Explain what the module helps prepare.
5. Show missing data or review state where relevant.
6. Close with human review and next-step framing.

Never imply the module makes final decisions, certifies results, gives legal/investment advice, or replaces professional review.

## CEO's OS Overview Video

**Duration:** 3-4 minutes.

**Opening:** "CEO's OS is a private executive DSS for turning fragmented operating signals into traceable Board Review Drafts."

**Must show:**

- CEO Overview.
- Reporting / Board Packs.
- Persisted snapshots.
- HTML Board Review Draft preview.
- Optional deep dive into M&A, Funding, and Compliance.

**Must say:**

- "Decision support, not autonomous decision-making."
- "Human Review Required."
- "Synthetic IberNova data is used for this demo."

**Must not say:**

- Board-approved output.
- Certified PDF.
- Autonomous AI.
- Legal/investment advice.
- SOC2/ISO certified.
- Production AI provider traffic.

## Video 11 - Practical User Manual / End-to-End Walkthrough

**Script:** "This practical walkthrough shows how a pilot user enters CEO's OS, navigates branches, creates a persisted Board Review snapshot, opens the HTML Board Review Draft, reviews workflow states, and uses browser-native print/save-as-PDF for a convenience copy."
