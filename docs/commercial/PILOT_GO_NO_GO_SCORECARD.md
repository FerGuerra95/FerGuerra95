# Pilot Go / No-Go Scorecard

**Phase:** C.15.6  
**Use:** Score prospects after discovery before proposing a controlled pilot.  
**Rule:** Score based on observable fit, not enthusiasm. Do not include real target names in this repo.

---

## Scoring Scale

| Score | Meaning |
|---:|---|
| 1 | Weak / absent |
| 2 | Some signal but unclear |
| 3 | Adequate / workable |
| 4 | Strong |
| 5 | Excellent |

For risk criteria, a higher score means better fit / lower risk.

---

## Scorecard

| Criterion | Score 1-5 | Notes |
|---|---:|---|
| Board-level pain | 0 | Is the pain tied to board, owners, IC, lenders, or executive committee? |
| Urgency | 0 | Is there a near-term decision or meeting? |
| Data availability | 0 | Can minimum data be provided safely? |
| Human reviewer available | 0 | Is there a named reviewer/sponsor? |
| Willingness to pay | 0 | Is there budget or paid-pilot openness? |
| Legal complexity | 0 | Can NDA/DPA/SOW path be handled without stalling? |
| Procurement friction | 0 | Can a controlled pilot start without enterprise procurement gate? |
| Strategic logo value | 0 | Would learning/reference value justify the pilot? |
| Risk of over-customization | 0 | Is the prospect willing to stay within current product boundaries? |
| Fit with current product | 0 | Can CEO's OS serve the use case today without major build? |

**Total:** `__/50`

---

## Classification

| Total | Decision | Meaning |
|---:|---|---|
| 40+ | Strong pilot candidate | Proceed to scoped pilot proposal and legal path |
| 30-39 | Qualified but needs scoping | Continue discovery; narrow scope before proposal |
| 20-29 | Discovery only | Do not propose pilot yet; learn and park |
| <20 | No-go | Do not pursue now |

---

## Automatic No-Go Conditions

No-go regardless of score if the prospect requires:

- board-approved output from CEO's OS;
- legal advice;
- investment advice;
- fairness opinion;
- certified compliance;
- certified PDF;
- autonomous AI decision-making;
- real client data before legal path;
- broad custom build before pilot;
- SOC2/ISO certification as a prerequisite for any discussion.

---

## Pilot Proposal Gate

Before proposal, confirm:

- sponsor exists;
- human reviewer exists;
- legal path is known;
- minimum data category is known;
- pilot deliverable is narrow;
- DSS/human-review limits are accepted.
